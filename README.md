# Contact Finder Pro v3.0

High-performance offline-first Android contact manager and Hostinger Cloud CSV engine for 10,000+ contacts.

---

## 🚀 Key Features in v3.0

1. **All-Inclusive Hostinger Backend (`index.php`)**:
   - One single PHP file handling two-way cloud sync, multi-CSV switching, per-device CSV routing, SMS syncing, and full web spreadsheet administration.
   - Zero reliance on Google Sheets or Google Apps Script. Pure Hostinger backend.
2. **Light Theme Glassmorphism UI**:
   - Clean, modern light design with soft glass cards, subtle borders, high-contrast typography, and intuitive icons.
3. **Automatic Device CSV Routing**:
   - Saves contacts with device tags (e.g. `Manufacturer_Model`) and routes to device-specific CSVs on Hostinger.
4. **Auto Scan Device Contacts & SMS**:
   - Automatically scans phone address books and SMS messages to discover unique contacts and uploads to Hostinger.
5. **Duplicate Contact Manager**:
   - Reminds users when duplicates exist.
   - In-app scan & clean for app database duplicates.
   - Scan & clean for device address book duplicate contacts based on exact phone numbers.
6. **Save All Contacts to Device**:
   - Export all synced contacts directly into the device's native address book in a single click from Settings.
7. **Multi-CSV Selector**:
   - Switch active CSV files directly from the app Settings dialog (`contacts.csv`, `sms.csv`, device CSVs).
